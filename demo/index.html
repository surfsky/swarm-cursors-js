Eight collaborators · each with a color
BLUEPRINT / 01 ● LIVE CANVAS
The blueprint breaks the page into five kinds of tasks: boxes, text, lines, media, and repeats. Each task carries its own dimensions and coordinates.
02 / THREE STEPS

Snapshot, rebuild, restore

The page is put on ice, then a group of collaborators brings it back piece by piece. None of it is a video replay.

SNAPSHOT

Break the page into tasks

Traverse the DOM and computed styles: backgrounds, borders, rounded corners, and shadows become boxes; text becomes text layers, along with font family, weight, line height, and color; single-sided borders and horizontal rules become pen lines; images, graphics, and canvases become media.

REBUILD

Unlock rows, deliver one by one

Tasks are grouped into vertical rows, each unlocked only after the previous row is built. A cursor flies to its task, presses, drags out a W × H box, then fills it or reveals an image. Text is typed letter by letter, and copies wait for their master to be placed.

FLOCK

Make them move like a team

Separation, attraction, and mouse avoidance combine so cursors make room when they get too close. When idle, they wander above the area awaiting construction; once the work is done, they fly off together through the top of the screen.

03 / USAGE

Just three APIs

The library is a single file with no dependencies and does not change your source page's structure: content is hidden with visibility and restored item by item.

  • targetElement to snapshot, as a selector string or node
  • cursorsNumber of concurrent cursors, default 8
  • speedReconstruction speed multiplier, 1 / 2 / 3
  • soundWeb Audio synthesized clicks and typing sounds
  • startOnLoadAutomatically start when created if true
  • showControlPanelShow the bottom-right control panel if true
  • restoreDelayRestoration delay in milliseconds
  • restoreOnFinishAutomatically restore the real page after building if true
  • restoreDelayRestoration delay in milliseconds
// Zero dependencies, import directly
import { SwarmCursors } from './swarm-cursors.js'

const swarm = new SwarmCursors({
  target: '#site',
  cursors: 8,
  restoreOnFinish: true,
})

await swarm.play()    // Snapshot → clear → rebuild → auto-restore
swarm.replay()       // Do it again
swarm.stop()         // Restore manually
