BLUEPRINT / 01 ● LIVE CANVAS
蓝图把页面拆成五类任务：盒子、文字、线条、媒体、重复项。每个任务都带自己的边长与坐标。
02 / 三步

快照、重建、归位

页面先进冰箱，再被一群协作者一件件搬回来。中间没有任何一段是录像回放。

SNAPSHOT

把页面拆成任务

遍历 DOM 与计算样式：有底色、描边、圆角、阴影的成为盒子；有文字的成为文本层，连同字族、字重、行高、颜色一起取走；单边描线与水平线变成钢笔线；图片、图形、画布变成媒体。

REBUILD

按行解锁，逐个交付

任务按纵向分行，一行建完才放下一行。光标领到任务先飞过去，按下、拖出 W × H 的框、再填色或揭图，文字逐字敲出来，复制项等母版先落位。

FLOCK

让它们像一群人

分离、趋近、避让鼠标三股力叠加，靠得太近会互相让位；空闲时光标在待建区上方游走，交付完成后一起从画面上沿飞走，像一场收工。

03 / 用法

三个 API 就够

库只有一份文件，没有依赖，也不改动你的源页面结构：内容靠 visibility 隐藏，还原时逐项恢复。

  • target要快照的元素，字符串选择器或节点
  • cursors并发光标数，默认 8
  • speed重建倍速，1 / 2 / 3
  • soundWeb Audio 合成的点击与打字声
  • startOnLoadtrue 时建好就自动开演
  • showControlPaneltrue 时显示右下角控制面板
  • restoreDelay还原延迟，单位毫秒
  • restoreOnFinishtrue 时建完自动还原真实页面
  • restoreDelay还原延迟，单位毫秒
// 零依赖，直接 import
import { SwarmCursors } from './swarm-cursors.js'

const swarm = new SwarmCursors({
  target: '#site',
  cursors: 8,
  restoreOnFinish: true,
})

await swarm.play()    // 快照 → 擦空 → 重建 → 自动还原
swarm.replay()       // 再来一遍
swarm.stop()         // 手动还原
